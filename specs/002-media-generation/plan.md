# Implementation Plan: Media Generation (Free-Stage MVP)

**Branch**: `002-media-generation` | **Date**: 2026-06-09
**Input**: Feature specification from `/specs/002-media-generation/research.md`

## Summary

Extend the Holodeck production pipeline with dialogue audio (.mp3) and B&W video (.mp4) using **only free, CPU-based tools**: gTTS (Google TTS), ImageMagick, and FFmpeg. No paid APIs, no GPU required.

```
19-Stage Text Pipeline  ──→  Media Pipeline  ──→  .mp4 with dialogue
(already implemented)        (3 new agents)        (stored in MinIO)
```

## Pipeline Stages (new)

### Stage 20: VoiceSynthesisAgent (parallel)
- **Input**: `context["script"]` + `context["voice_direction"]`
- **Action**: Parse script for dialogue lines → call gTTS per line → concat per scene → upload .mp3 to MinIO
- **Output**: `context["dialogue_audio_urls"]`

### Stage 21: FrameRendererAgent (parallel with Stage 20)
- **Input**: `context["storyboard"]` + `context["animation"]`
- **Action**: Convert scene/animation descriptions into B&W SVG frames via ImageMagick → rasterize as PNG → upload to MinIO
- **Output**: `context["frame_urls"]`

### Stage 22: VideoAssemblerAgent (sequential — depends on 20 + 21)
- **Input**: Frame URLs + dialogue URLs
- **Action**: Concat frames at 24fps via FFmpeg → multiplex dialogue tracks → B&W filter → encode as H.264 .mp4 → upload to MinIO
- **Output**: `context["final_video_url"]`

## Parallel Execution

```
    VoiceSynthesis    FrameRenderer
    (gTTS per line)   (ImageMagick per scene)
          │                 │
          └──────┬──────────┘
                 │
          VideoAssembler
          (FFmpeg concat + amix)
                 │
            final .mp4
```

Stages 20 and 21 are independent → run in `asyncio.gather()`.
Stage 22 depends on both → runs sequentially after.

## Cost per Episode

| Stage | Tool | Cost | GPU | Time |
|-------|------|------|-----|------|
| VoiceSynthesis | gTTS | $0 | No | ~5s |
| FrameRenderer | ImageMagick | $0 | No | ~30s |
| VideoAssembler | FFmpeg | $0 | No | ~15s |
| **Total** | | **$0** | **No** | **~50s** |

## Key Design Decisions

1. **Music and SFX skipped** for MVP — video plays with dialogue only
2. **No paid API keys required** — gTTS uses Google's free endpoint
3. **No GPU required** — all tools run on CPU
4. **No additional LLM calls** at render time — all descriptions already generated by text pipeline
5. **SVG templates** are static Python strings, not AI-generated — deterministic, fast, consistent

## Implementation Order

1. System deps (Dockerfile): ffmpeg, imagemagick
2. Python deps: gtts, ffmpeg-python
3. MinIO media_storage helper
4. FrameRendererAgent (simplest — pure ImageMagick)
5. VideoAssemblerAgent (pure FFmpeg)
6. Wire into pipeline (stages 21–22)
7. VoiceSynthesisAgent (gTTS)
8. Wire into pipeline (stage 20)
9. Tests
