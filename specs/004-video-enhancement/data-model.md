# Data Model: Video Enhancement

## New Data Entities

### CharacterVisual

Per-character visual configuration used by FrameRendererAgent to render detailed SVGs.

```
CharacterVisual {
  name: str                    // Character name (matches script)
  height_ratio: float          // Relative height (1.0 = default, 0.8 = short, 1.2 = tall)
  build: str                   // "slim", "average", "athletic", "heavy"
  hair_style: str              // "short", "long", "bald", "ponytail", "curly"
  clothing: str                // "uniform", "civilian", "formal", "cloak"
  accessory: str               // "hat", "cape", "badge", "weapon", "none"
  face_shape: str              // "round", "oval", "square", "angular" (deferred — not yet consumed by T099)
  voice_model: str             // Piper voice model name (e.g. "en_US-lessac-medium")
}
```

**Storage**: Generated by CharacterDesigner agent, passed via `context["character_visuals"]`.

### ColorGrade

Per-scene color grading configuration.

```
ColorGrade {
  scene: str                   // Scene identifier
  mood: str                    // "warm", "cool", "sepia", "noir", "neutral", "vivid"
  preset: str                  // FFmpeg filter preset name
  params: dict                 // Optional filter parameters
  // Default mappings:
  // warm: colorbalance=rs=.15:gs=.05:bs=-.1
  // cool: colorbalance=rs=-.1:gs=-.1:bs=.2
  // sepia: colorchannelmixer=.393:.769:.189:0:.349:.686:.168:0:.272:.534:.131:0
  // noir: colorchannelmixer=.3:.4:.3:0:.3:.4:.3:0:.3:.4:.3:0 (B&W)
  // neutral: no filter
  // vivid: eq=saturation=1.5
}
```

**Storage**: Generated from scene mood analysis, stored in `context["color_grades"]`.

### CameraMove

Camera motion configuration for a scene segment.

```
CameraMove {
  scene: str                   // Scene identifier
  start_zoom: float            // Zoom at start of scene (1.0 = normal)
  end_zoom: float              // Zoom at end of scene (2.0 = 2x)
  pan_x_start: float           // Pan X at start (pixels)
  pan_x_end: float             // Pan X at end
  pan_y_start: float           // Pan Y at start
  pan_y_end: float             // Pan Y at end
  duration_frames: int         // Total frames for this camera move
}
```

**Storage**: Generated by scene analysis, applied in zoompan filter. **Note**: No task currently populates this — T098 should add a stub that parses scene descriptions for camera direction hints (e.g., "close-up" → zoom in, "wide shot" → zoom out, "tracking" → pan).

### PiperVoice

Definition of available piper TTS voices.

```
PiperVoice {
  model_id: str                // e.g. "en_US-lessac-medium"
  gender: str                  // "male", "female"
  display_name: str            // "US Female (Lessac)"
  model_path: str              // Path to .onnx model file
  config_path: str             // Path to .json config file
  speed: float                 // Playback speed (1.0 = normal)
}
```

**Storage**: Hardcoded map of available voices. Models downloaded on first use.

## Modified Context Keys

| Key | Type | Description | Set By |
|-----|------|-------------|--------|
| `character_visuals` | `dict[str, CharacterVisual]` | Visual config per character | CharacterDesigner or defaults |
| `color_grades` | `list[ColorGrade]` | Per-scene color grading | Scene analysis |
| `camera_moves` | `list[CameraMove]` | Per-scene camera motion | Scene analysis |
| `frame_layouts` | `list[dict]` | Character positions per frame | FrameRendererAgent |

## Modified Agent Metadata (AgentOutput.metadata)

### FrameRendererAgent

| Field | Type | Description |
|-------|------|-------------|
| `characters_per_frame` | `int` | Average characters visible per frame (1 or 2) |
| `lip_sync_enabled` | `bool` | Whether mouth animation was applied |
| `background_depth` | `int` | Number of background layers (1-3) |

### VideoAssemblerAgent

| Field | Type | Description |
|-------|------|-------------|
| `camera_motion_type` | `str` | "none", "zoom", "dolly", "pan", "combined" |
| `color_grade_applied` | `str` | Color grade preset name |
| `smooth_zoom` | `bool` | Whether single-pass zoom was used |

### VoiceSynthesisAgent

| Field | Type | Description |
|-------|------|-------------|
| `tts_engine` | `str` | "piper" or "gtts" |
| `voice_models` | `list[str]` | Piper model IDs used |
